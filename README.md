# 🏡 Wanderbricks – SQL Data Analytics

**End-to-End SQL Data Analytics Project using Databricks**

## 1. Project Overview

Wanderbricks is a SQL-based data analytics project focused on analyzing a property booking platform's business performance using Databricks SQL.

The project explores booking transactions, revenue performance, customer activity, property distribution, host performance, city-level trends, cancellation patterns, and property amenities.

Using SQL queries across a relational dataset containing 9 tables, this project transforms raw business data into meaningful insights to understand operational performance and identify potential business growth opportunities.

The analysis focuses on answering real-world business questions through SQL techniques, aggregations, joins, subqueries, and analytical functions.

## 2. Business Objectives.

The primary objectives of this project are:

- Evaluate overall business performance through key performance indicators (KPIs).
- Analyze total revenue and average booking value.
- Identify monthly and yearly booking trends.
- Understand booking cancellation patterns and cancellation rates.
- Analyze property distribution across different cities.
- Identify top-performing hosts based on property listings.
- Evaluate property types and their booking performance.
- Identify cities contributing the highest revenue.
- Analyze the popularity and distribution of property amenities.
- Generate actionable insights to support data-driven business decisions.

## 3. Dataset Description

The project uses the Wanderbricks dataset, consisting of **9 relational tables** containing information about users, bookings, properties, hosts, cities, and amenities.

The tables identified in the current SQL analysis include:

| Table Name | Description |
|---|---|
| users | Contains user-related information. |
| bookings | Contains booking transactions, dates, amounts, and booking statuses. |
| properties | Contains property information, types, and base prices. |
| hosts | Contains property host information. |
| cities | Contains city-level information. |
| amenities | Contains available property amenities. |
| property_amenities | Maps properties to their available amenities. |

## 8. Key Findings and Business Insights

Based on the initial KPI analysis:

1. **Platform Scale:** Wanderbricks has 124,509 users and 72,247 bookings, providing a substantial dataset for understanding platform activity.

2. **Property Coverage:** The platform contains 18,163 properties distributed across 39 cities.

3. **Revenue Performance:** Confirmed bookings generated approximately 9.91 million in total revenue.

4. **Average Booking Value:** The average confirmed booking value is 552.37.

5. **Booking Cancellations:** The overall cancellation rate is 21.16%, highlighting an area that requires further investigation.

6. **Property Pricing:** The average property base price is 181.60.

### Potential Business Recommendations

- Investigate the reasons behind booking cancellations to identify opportunities for reducing cancellation rates.
- Focus on high-performing cities to understand the factors driving revenue.
- Analyze property types to identify categories attracting more bookings.
- Support hosts with fewer listings or lower performance through targeted business strategies.
- Use popular amenities to improve property listing attractiveness and customer experience.
